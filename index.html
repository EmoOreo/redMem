    Bookmarklet

    A one-click helper to send the current Reddit post to RedMem.

    1. Show your bookmarks bar (Ctrl+Shift+B or ⌘+Shift+B).
    2. Drag the button below onto the bookmarks bar.
    3. Open a Reddit post and click the bookmarklet. It copies the post URL to your clipboard and opens RedMem.
    4. Paste the URL into the “Add a Reddit post” field (or let RedMem auto-fill if it is already open).

    Help & collection methods
    
      
    

      
    
        
    
          
    A. URL entry & retrieval
    
          
    
            Paste a Reddit post URL. RedMem attempts a public, browser-compatible retrieval. If Reddit or the browser blocks it (CORS, access controls), the record is saved as link-only and clearly marked. RedMem never claims a successful retrieval unless the data was actually received and parsed.
          
    
        
    

        
    
          
    C. Bookmarklet
    
          
    
            Use the bookmarklet while viewing a Reddit post to copy the URL and open RedMem. This works without a backend and respects browser security. On mobile, copy and paste manually.
          
    
        
    

        
    
          
    D. File import
    
          
    
            Import a RedMem JSON export for full fidelity. Markdown and plain-text files are accepted in a limited form (URLs are extracted and added as link-only records). Imported HTML is treated as text and never executed.
          
    
        
    

        
    
          
    Data safety
    
          
    
            All Reddit content and imported files are treated as untrusted. Text is rendered with safe DOM APIs, URLs are validated to HTTP/HTTPS Reddit domains, and no scripts are ever evaluated.
